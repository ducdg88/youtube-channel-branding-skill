# NAMING + SEO PROTOCOL

## Niche matrix
Lập: core niche → micro-niches → creator value proposition → target geo/language → tone → format → potential advertisers (nếu có nguồn). Không bịa ad prices.

## Name generation
Generate 25 names grouped: 7 coined, 6 compound, 6 evocative, 6 descriptive hybrid.
Đánh giá 0-100 theo: conflict risk (25), memorability (15), pronunciation (15), relevance (15), visual identity (15), brand extensibility (10), handle prospects (5); chỉ là nhận định chiến lược, không phải pháp lý.

## Collision screening
For top 5 record:
- exact quoted web search query + retrieved matching pages + check date
- YouTube channel search + exact phrase + nonspaced variation
- handle candidate syntax, format, whether Studio confirmed vs UNVERIFIED
- trademark search result if performed and market chosen

**No result in web search != confirmed unique**. Channel display names can repeat; @handles unique. Final action to confirm: YouTube Studio → Customization → Profile → Handle. References: https://support.google.com/youtube/answer/11585688 and https://support.google.com/youtube/answer/2657964

## SEO deliverables
- 30 keywords tagged core, supporting, long-tail, series, branded; no guessed volume/difficulty.
- 5 content pillars, 10 starting video titles, channel description international EN and Vietnamese concept summary.
- Tags/channel keywords are supporting context, not a substitute for video relevance or audience retention.
- Series must map to real content to be published (e.g. logging → sawmill → seasoning → CNC → final polish). Avoid false claims of actual production, exclusive access or provenance.
